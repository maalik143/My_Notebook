# My Notebook - Advanced Document & Code Reader / Editor

A responsive multi-tab desktop notebook and viewer designed for reading, editing, and managing code, markdown, PDFs, and binary data.

## Features
- **Document Viewing**: High-speed PDF rendering, Markdown live preview, rich text viewing.
- **Binary Inspector**: Hex inspection and file metadata analysis.
- **Code Editor**: Syntax highlighting, search & replace, line numbering.
- **Windows Integration**: Registry entry script (`add_to_right_click.reg`) to open any file directly.

## Requirements
- Python 3.8+
- Dependencies: `pip install -r requirements.txt` (Pillow, PyMuPDF, etc.)

## How to Run
Double-click: `run_notebook.bat`
Or run via terminal:
```bash
python notebook.py
```
