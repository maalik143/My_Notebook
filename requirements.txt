# My Notebook - Advanced Multi-Format Notebook

Feature-rich desktop notebook with Windows right-click integration.

## Features
- Rich text editor
- Support for multiple formats: PDF, HTML, Binary files
- Windows right-click context menu integration
- Export and preview capabilities

## How to Run
Double-click: run_notebook.bat

## Windows Integration (Optional)
To add "Open with Notebook" to right-click menu:
1. Right-click: add_to_right_click.reg
2. Click "Merge"
3. Confirm when prompted

## Requirements
`.
pip install -r requirements.txt
